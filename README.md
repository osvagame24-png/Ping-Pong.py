# Ping Pong: Installation and Player Guide

## About the game

Ping Pong is a small, single-player paddle game for Windows. Control the paddle on the left and try to hit the ball past the computer-controlled paddle on the right. The game is provided as a standalone `.exe` application.

## Before you begin

You’ll need a Windows computer and the `PingPong.exe` game file. Download the file from the person or source that shared the game, and save it somewhere easy to find, such as **Downloads**.

The game does **not** require Python, Command Prompt, or a separate installer. An internet connection is needed to download the file, but not to play.

## Install and start the game

There is no setup wizard: downloading the executable is all that’s needed to install it.

1. Open **File Explorer** and go to the folder where `PingPong.exe` was saved.
2. Double-click **`PingPong.exe`** to launch the game.
3. If Windows displays a security warning, check that the filename and source are the ones you expect. Only run the file if you trust the person or source that provided it. The game does not need administrator access.
4. When the game window appears, click it once so it has keyboard focus.

To make the game easier to find later, leave the executable in a folder where it won’t be accidentally deleted. You can also create a shortcut: right-click `PingPong.exe`, choose **Create shortcut**, and move the shortcut wherever convenient. Keep the original `.exe` in place; the shortcut points to it.

## How to play

You control the **black paddle on the left**. The **red paddle on the right** is controlled by the computer.

| Key | Action |
|---|---|
| **W** | Move your paddle up |
| **S** | Move your paddle down |

Keep the game window active while playing so it receives the keyboard input. Try to line up your paddle with the ball and hit it back toward the computer’s paddle. The number displayed on the screen is your score; it increases when you hit the ball with your paddle.

## Ending a round and playing again

A round ends when the ball gets past either paddle. The game does not currently have an in-game restart button. To play another round, close the game window with the **X** button, then open `PingPong.exe` again.

## Troubleshooting

- **The game doesn’t start:** Confirm that the file is named `PingPong.exe` and that it finished downloading. Try opening it again from File Explorer.
- **The game window opens, but the keys don’t work:** Click inside the game window, then press **W** or **S**.
- **Windows shows a security warning:** Windows may warn about applications from an unverified publisher. Only proceed if the file came from a source you trust. Don’t run it as administrator.
- **The game closes after the ball passes a paddle:** That’s the end of the round. Reopen the executable to start again.

**In short:** download `PingPong.exe`, open it, use **W** and **S** to move the left paddle, and reopen the game when a round ends.
